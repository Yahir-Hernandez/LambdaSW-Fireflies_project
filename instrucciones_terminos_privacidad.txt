TUTORIAL: ARREGLAR LOS POPUPS Y ENLACES DE TERMINOS Y PRIVACIDAD
===========================================================================

Este documento explica, paso a paso y en lenguaje sencillo, que cambiar y
como, para resolver los problemas reportados. Solo hay que abrir los archivos
indicados, buscar el fragmento mencionado y reemplazarlo por el nuevo.


PROBLEMAS QUE VAMOS A RESOLVER
---------------------------------------------------------------------------
1. Los popups (ventanas emergentes) de Terminos y Aviso de Privacidad no usan
   la tipografia ni el estilo del resto del sitio.
2. El boton "Entendido" no esta centrado dentro del popup.
3. Los enlaces del footer "Aviso de privacidad" y "Terminos y condiciones" no
   hacen nada al hacer clic, y los popups solo existen en la pagina de registro.
4. Los correos que aparecen en los textos legales son ficticios; deben ser
   lambdasoftworks@gmail.com.
5. En el footer, los dos enlaces de abajo estan pegados; hay que separarlos.


IDEA GENERAL DE LA SOLUCION
---------------------------------------------------------------------------
Hoy los popups y su codigo JavaScript viven "incrustados" dentro de la pagina
de registro (sign_up.html), por eso solo funcionan ahi. La estrategia es:

- Sacar el contenido de los popups a un archivo aparte (un "parcial") que se
  pueda reutilizar en todas las paginas.
- Sacar el JavaScript a un archivo aparte que se cargue en todo el sitio.
- Incluir ese parcial y ese script tanto en la plantilla base (que comparten
  todas las paginas) como en la de registro (que es independiente).
- Conectar los enlaces del footer para que abran esos popups.
- Mover y arreglar los estilos del popup para que usen la tipografia del sitio
  y centren el boton.

PASO 2 - CREAR EL ARCHIVO JAVASCRIPT COMPARTIDO
===========================================================================

Archivo a crear: sistema_app/static/script/legal_modals.js

Este codigo abre y cierra los popups en cualquier pagina. Funciona asi:

- Cualquier boton o enlace con el atributo data-open-modal="terms-modal"
  (o ="privacy-modal") abre ese popup.
- Cualquier boton con data-close-modal cierra el popup que lo contiene.
- El boton "Entendido" (.tc-modal__accept) cierra el popup y, SOLO si existe la
  casilla de aceptar terminos (id_terms_accepted, que solo esta en el registro),
  la marca como aceptada. Por eso no falla en otras paginas.
- Tambien cierra al hacer clic fuera del popup o al presionar la tecla Escape.

Pegar exactamente este contenido:

---------------------------------------------------------------------------
// Logica compartida de los modales legales (Terminos y Condiciones / Aviso de
// Privacidad). Disponible en cualquier pagina que incluya partials/legal_modals.html
// y enlaces/botones con [data-open-modal="<id-del-modal>"].
(function () {
	function openModal(id) {
		const modal = document.getElementById(id);
		if (modal) {
			modal.classList.add('is-open');
			document.body.style.overflow = 'hidden';
		}
	}

	function closeModal(modal) {
		if (modal) {
			modal.classList.remove('is-open');
			document.body.style.overflow = '';
		}
	}

	// Abrir: cualquier elemento con data-open-modal
	document.querySelectorAll('[data-open-modal]').forEach(function (trigger) {
		trigger.addEventListener('click', function (e) {
			e.preventDefault();
			openModal(trigger.dataset.openModal);
		});
	});

	// Cerrar: boton con data-close-modal
	document.querySelectorAll('[data-close-modal]').forEach(function (btn) {
		btn.addEventListener('click', function () {
			closeModal(btn.closest('.tc-modal-overlay'));
		});
	});

	// Aceptar ("Entendido"): marca la casilla de terminos si existe y cierra
	document.querySelectorAll('.tc-modal__accept').forEach(function (btn) {
		btn.addEventListener('click', function () {
			const checkbox = document.getElementById('id_terms_accepted');
			if (checkbox) checkbox.checked = true;
			closeModal(btn.closest('.tc-modal-overlay'));
		});
	});

	// Cerrar al hacer click en el overlay
	document.querySelectorAll('.tc-modal-overlay').forEach(function (overlay) {
		overlay.addEventListener('click', function (e) {
			if (e.target === overlay) closeModal(overlay);
		});
	});

	// Cerrar con Escape
	document.addEventListener('keydown', function (e) {
		if (e.key === 'Escape') {
			document.querySelectorAll('.tc-modal-overlay.is-open').forEach(closeModal);
		}
	});
})();

PASO 5 - ARREGLAR LOS ESTILOS DEL POPUP (TIPOGRAFIA Y BOTON CENTRADO)
===========================================================================

Archivos a editar:
   sistema_app/static/css/user/registro.css
   sistema_app/static/css/user/base.css

POR QUE: los estilos del popup (.tc-modal...) estan hoy en registro.css, que
SOLO se carga en la pagina de registro. Como ahora los popups aparecen en todo
el sitio (y base.html solo carga base.css), hay que MOVER esos estilos a
base.css. De paso, arreglamos la tipografia y el centrado.


--- 5.1 Cortar los estilos de registro.css ---

En registro.css, buscar el bloque que empieza con el comentario:
   /* -- Modal T&C / Privacidad -- */

y que abarca desde .tc-modal-overlay hasta .tc-modal__accept (incluye tambien
@keyframes fadeIn). Va aproximadamente de la linea 334 a la 423. CORTAR todo ese
bloque (se pega en base.css en el siguiente paso).

IMPORTANTE: dejar en registro.css las reglas de .terms-scroll-box,
.terms-check-row, .terms-checkbox, .terms-label, .terms-link-btn y .btn-success:
esas son exclusivas del formulario de registro y se quedan.


--- 5.2 Pegar y arreglar los estilos en base.css ---

En base.css, pegar el bloque que se corto (un buen lugar es justo despues de las
reglas de .auth-dialog, que son popups parecidos). Al pegarlo, aplicar TRES
ajustes:

1) Tipografia del titulo. Buscar dentro de lo pegado:

   .tc-modal__header h3 {
     font-family: 'DM Serif Display', serif;
     ...
   }

   Cambiar la fuente por la del sitio:

   .tc-modal__header h3 {
     font-family: var(--font-title);
     ...
   }

2) Tipografia del cuerpo. En la regla .tc-modal__body { ... }, agregar una linea
   para usar la fuente de texto del sitio:

   .tc-modal__body {
     flex: 1;
     overflow-y: auto;
     padding: 20px 24px;
     font-family: var(--font-body);   /* <- linea nueva */
     font-size: 0.84rem;
     color: var(--text-dim);
     line-height: 1.7;
   }

3) Centrar el boton "Entendido". Buscar:

   .tc-modal__footer {
     padding: 16px 24px 20px;
     border-top: 1px solid rgba(255,255,255,.1);
     display: flex;
     justify-content: flex-end;
   }
   .tc-modal__accept {
     min-width: 130px;
   }

   Cambiarlo por (centra el contenido y deja el boton con ancho automatico para
   que no se vea estirado):

   .tc-modal__footer {
     padding: 16px 24px 20px;
     border-top: 1px solid rgba(255,255,255,.1);
     display: flex;
     justify-content: center;
   }
   .tc-modal__accept {
     min-width: 130px;
     width: auto;
   }

SOBRE LAS ANIMACIONES: el popup usa "animation: slideUp ..." y
"animation: fadeIn ...". Asegurarse de que en base.css existan los
@keyframes fadeIn y @keyframes slideUp. El @keyframes fadeIn viene incluido en
el bloque que se movio. Si al moverlo base.css quedara con fadeIn duplicado,
borrar uno de los dos (son identicos). Si NO existe @keyframes slideUp en
base.css, agregarlo:

   @keyframes slideUp {
     from { opacity: 0; transform: translateY(-12px) scale(0.98); }
     to   { opacity: 1; transform: translateY(0) scale(1); }
   }
